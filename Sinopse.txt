Esse é um projeto da matéria de Introdução à Modelagem Matemática, aqui vai o código utilizado para modelar a taxa de câmbio e o arquivo com os dados diários do valor do real desde 01/07/1994  

O projeto faz a modelagem e a projeção da taxa de câmbio utilizando o modelo matemático Ornstein-Uhlenbeck (OU), um processo que assume que o valor do câmbio tende a reverter para uma média de longo prazo ao longo do tempo.

O programa funciona em três etapas principais:

Tratamento de Dados e Filtro de Período: Ele lê um arquivo histórico (cambio.csv) e permite que você escolha o período exato que deseja analisar diretamente pela linha de comando definindo uma data de início, fim ou focando apenas nos últimos anos.

Ajuste do Modelo: O código calcula os parâmetros estatísticos do modelo, velocidade de reversão à média, o valor de equilíbrio e a volatilidade, e valida a estabilidade dos dados através de um teste de estacionaridade (ADF) otimizado.

Simulação e Projeção Futura: Com base nos parâmetros calculados, ele roda uma Simulação de Monte Carlo para projetar cenários futuros para o câmbio. É possível definir quanto tempo à frente ele vai projetar (o horizonte de projeção), plotando gráficos da série histórica junto com as bandas de incerteza do futuro e relatórios de erro.

This is a project for the Introduction to Mathematical Modeling course. Here is the code used to model the exchange rate and the file containing the daily values of the Brazilian Real since July 1st, 1994. (real/dolar)

The project models and projects the exchange rate using the Ornstein-Uhlenbeck (OU) mathematical model—a process that assumes the exchange rate tends to revert to a long-term mean over time.

The program works in three main steps:

Data Processing and Period Filter: It reads a historical file (cambio.csv) and allows you to select the exact period you want to analyze directly through the command line by setting a start date, end date, or focusing only on recent years.

Model Fitting: The code calculates the statistical parameters of the model—mean reversion speed, long-term equilibrium value, and volatility—and validates data stability using an optimized Augmented Dickey-Fuller (ADF) stationarity test.

Simulation and Future Projection: Based on the calculated parameters, it runs a Monte Carlo Simulation to project future exchange rate scenarios. You can define how far ahead it should project (the projection horizon), generating plots of the historical series alongside future uncertainty bands and error reports.
